# Demo Assets

This folder contains public-safe demo artifacts for `DemoApp`.

## What is here

- `scenarios/` — deterministic showcase scenarios
- `contracts/` — sample task, verification, and release contracts
- `reports/` — sample gate outputs and blocked release decision

## What is not here

- private project ideas
- real user data
- secrets
- live provider output
- runtime-generated production artifacts

These files are examples only. They exist to explain how NEXUS works in a
public, zero-key, recruiter- and investor-friendly format.
