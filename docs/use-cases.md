# NEXUS Use Cases

These examples are public-safe and use `DemoApp` or generic system behavior
only.

## iOS QA orchestration

NEXUS can plan iOS work, route sample implementation tasks to `SWIFT`, require
`SENTINEL` simulator evidence, and block release until the macOS/Xcode runtime
proof exists.

## Backend API delivery

NEXUS can route a sample API task to `CORE`, keep scope inside a typed contract,
send the result through `AUDITOR`, and attach evidence before a release decision
is considered.

## Compliance and privacy review

`WARDEN` can review sample privacy handling, permissions, and public-safe
compliance surfaces while keeping the output evidence-linked and redacted.

## Sprint execution

Founder intent can be translated into a governed sprint flow:

Founder intent
→ NEXUS decision
→ SHEPHERD plan
→ execution tasks
→ verification gates
→ release posture

## Provider routing and batch cost optimization

NEXUS can separate realtime reasoning from non-blocking batch work, track cost,
and keep low-risk summaries out of the critical gate path.

## Release gating

Release is not a chat decision. It is based on gate evidence, approval status,
runtime proof, and contract-linked artifacts.

## Command Center operations

The Command Center prototype shows mission control, task queue, gate posture,
runtime health, evidence timeline, approvals, safety signals, and release
control in one surface.
