# Public Repo Boundary

## Allowed in the public repo

- NEXUS OS architecture
- agent definitions and operating standards
- contracts and state-machine design
- demo data
- dashboard shell and static showcase surface
- policies
- sample reports
- public-safe eval scenarios

## Not allowed in the public repo

- private project ideas
- private app details
- secrets
- real users
- real customer data
- private business plans
- live provider credentials
- production data exports

## Public-safe default

Use `DemoApp`, generic sample APIs, generic iOS sample screens, and public-safe
reports when demonstrating the system.
