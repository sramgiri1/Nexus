# NEXUS Public Roadmap

## Current foundation

NEXUS already defines:

- contracts
- state machine architecture
- agent standards
- runtime architecture
- operator platform architecture
- data protection and DB safety boundaries
- security boundary
- OS reliability model
- capability registry
- observability, evals, and artifact models

## Current showcase step

Demo and Showcase Mode makes the public repo easier to evaluate without:

- API keys
- private app code
- real customer data
- live provider calls

## Near-term public roadmap

### Runtime enforcement

Wire policies, capabilities, security boundaries, and runtime routing into live
execution.

### API and durable DB

Introduce the future API boundary and durable DB path without bypassing the
governor, contracts, or state machine.

### Xcode Runner

Implement the macOS/Xcode runtime path needed for real iOS verification
evidence.

### Marketplace / Agent-as-a-Service direction

Explore how governed agents, capabilities, and approvals could become reusable
platform primitives.

### Production hardening

Add stronger reliability, security enforcement, backups, retention, and
operational runbooks.

## Public safety note

This public repo uses `DemoApp` only. Private product work, private business
plans, and customer-specific execution should live in separate private repos.

## Screenshots and showcase assets

Simple public-safe placeholders can live in `docs/images/`. Real polished
screenshots can be added after public cleanup or from a clean public repo
export.
