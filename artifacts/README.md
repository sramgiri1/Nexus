# Artifact Examples

This folder currently contains example artifact metadata only.

What is here now:

- sample artifact registry data for `DemoApp`
- placeholder references for reports, test output, `xcresult`, approval results,
  and eval output

What is not here yet:

- live runtime-generated artifacts
- database-backed artifact metadata
- object storage integration
- secrets or private data

Future direction:

- the DB stores artifact metadata later
- large artifacts live in filesystem or object storage later
- artifact references should link to evidence and traces
- no secrets or private data should be stored here
