# OS Roadmap Status

This folder stores NEXUS OS roadmap metadata used by Command Center and phase
checkers.

- `nexus-phases.json` is the roadmap phase catalog.
- `phase-status.json` is the status registry for completed, current, and planned
  NEXUS OS phases.
- `updatePhaseStatus.js` provides a small shared helper for future phases to
  update status without rewriting the schema.

Project progress does not belong in the OS roadmap. Project-specific status
belongs under Projects / Project Progress surfaces.
