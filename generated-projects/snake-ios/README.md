# Snake iOS

Generated by NEXUS P83.3 as an admitted local workspace for the founder Snake
iOS test case.

## Scope

- Platform: iOS-first SwiftUI/SpriteKit scaffold.
- Local validation: `swift run SnakeIOSAppTests` and `swift build`.
- Workspace root: `generated-projects/snake-ios`.

## Safety

This workspace is local-only. It does not call providers, execute Nexus tools or
workers, write DB state, deploy, release, export, package, call external
networks, or spend provider budget.

## Files

- `Sources/SnakeIOSApp/SnakeIOSApp.swift` provides the SwiftUI shell.
- `Sources/SnakeIOSApp/GameScene.swift` renders the SpriteKit scene.
- `Sources/SnakeIOSApp/GameState.swift` owns deterministic Snake rules.
- `Sources/SnakeIOSApp/SnakeTypes.swift` defines shared game types.
- `Sources/SnakeIOSApp/Theme.swift` defines display colors.
- `Tests/SnakeIOSAppTests/GameStateTests.swift` covers core game behavior.
